# tumamu — 思想

出典: DORAインタビュー「安田侃」 https://dora.or.jp/our_activity/kanyasuda/ （2025年秋）

## 出発点

安田侃は、彫刻でいちばん大事なのは「触れることができる」ことだと言う。人の体は脳より先に触覚が育つので、触れることは人間にとっていちばん原始的な行為だ、とも。そして今の都市は「触れてはいけないもの」でできていて、その中に思わず触ってみたくなるものを置きたい、と語っている。

XRは今のところ「見る」メディアで、触覚はほとんど扱えていない。tumamu はこれを逆手に取って、XRを「触れる」ためのメディアとして使う。

## 作品に置き換える5つの考え

### 1. 壁を「触れていいもの」に変える
壁は「触れてはいけないもの」の代表で、汚さない・寄りかからない・もたれない対象として扱われている。tumamu では、部屋のいつもの壁に手を当てたときに、壁が初めて反応を返す。

### 2. 触覚は現実のほうに任せる
XRで触覚を作り込もうとはしない。MRで手を当てるのは本物の壁なので、冷たさも硬さもざらつきも本物だ。デジタル側が受け持つのは、触れたことへの「応答」だけにする。手ざわりは現実、応答は仮想という役割分担で、XRで触覚が欠けている問題を片づける。

### 3. 形のないものを形にする
「形のないものを形にする」は安田の彫刻の目標だ。壁の奥には、その場所が抱えている見えない材質（記憶）が眠っていると考える。つまむと、それが形のある塊として指先に出てくる。美唄なら、石炭（炭鉱の記憶）、大理石（安田の素材）、木（旧栄小学校の校舎）がそれに当たる。

### 4. 何にも触れない「隙間」
「天モク」では中央の柱が地面からわずかに浮いていて、その隙間が表現の核になっている。投げた材質も床に落として終わりにはしない。最後は床からわずかに浮いて止まり、何にも触れない状態で部屋に残る。

### 5. 意味がなくても触りたくなる
「意心帰」に子どもが駆け寄ったのは、説明があったからではなく、触ってみたくなったからだ。だから tumamu には点数も目標もチュートリアルの文言も置かない。触ったら何かが返ってくる、そのことだけで手が伸びるように作る。何が出てくるか、どこに残るかは人によって変わるので、結果的にその人の心を映す形になる。

## やらないこと
- ゲーム化（スコア・クリア条件・競争）
- 説明テキストで体験を導くこと
- 「触ってはいけない」演出（警告表示やUIパネルで壁を覆うこと）
